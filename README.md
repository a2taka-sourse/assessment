# assessment

「あなたのいいところ＋おすすめ企画」診断

N予備校プログラミング入門コースで作った「あなたのいいところ診断」を、Haircut1000美学7軸診断へ発展させたバニラJSアプリ。

## 機能

7問の選択式アンケートに答えると：

- **あなたのいいところ**（軸に紐づく1対1マッピング）
- **あなたにおすすめの企画**（最高得点軸の中からランダム選出）

の2段で結果が表示される。「企画をもう一個ひく」ボタンで同軸内の別企画案を引き直すことができる。

## 美学7軸

| 軸 | 内容 |
|---|---|
| α | 権威フォーマット流用 |
| β | 聖域×世俗の執着 |
| γ | 死蔵物への逆張り愛 |
| δ | きもさの自己拡張 |
| ε | 統合・縮約 |
| ζ | 大喜利力縛り勝負 |
| η | 意味生成による意味解体 |

## 構成

```
├── index.html      # アンケートUI
├── assessment.js   # 質問遷移・スコア計算・結果生成
├── assessment.css  # ダーク基調のモダンCSS
├── questions.js    # 質問データ
└── results.js      # 軸ごとの「いいところ」と企画案データ
```

## 使い方

`index.html` をブラウザで開く。
